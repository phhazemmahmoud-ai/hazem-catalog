# مشروع كتالوج صيدلية الحازم

## الملفات
- index.html          -> الموقع اللي بيشوفه العميل
- admin.html           -> لوحة التحكم (تسجيل دخول + إدارة منتجات)
- firebase-config.js   -> بيانات الاتصال بقاعدة البيانات (مشتركة بين الملفين)
- database-rules.json  -> قواعد أمان قاعدة البيانات (لازم تتنسخ في Firebase)

ملحوظة: رفع صور المنتجات مش مفعّل دلوقتي (محتاج ترقية خطة Firebase لـ Blaze).
المنتجات بتظهر بمربع لون وأول حرف من الاسم بدل الصورة. تقدروا تفعّلوا الصور
لاحقًا وقتها نضيف الميزة دي تاني.

## خطوات لازم تعملوها قبل الاستخدام

### 1) حساب دخول للوحة التحكم — تم ✅
### 2) تفعيل Email/Password — تم ✅

### 3) ظبطوا قواعد أمان قاعدة البيانات (مهم جدًا)
دلوقتي القاعدة شغالة في "test mode" يعني أي حد على النت يقدر يكتب فيها. لازم تستبدلوها بالقواعد الأصح:
- من Realtime Database -> تبويب Rules -> امسحوا اللي موجود والصقوا محتوى ملف database-rules.json -> Publish

القاعدة دي معناها: أي حد يقدر يشوف المنتجات (عشان الموقع يشتغل)، بس محدش يقدر يضيف أو يعدل أو يحذف غير اللي مسجل دخول من لوحة التحكم.

### 4) رفع الملفات على استضافة
لازم الملفات (index.html, admin.html, firebase-config.js, database-rules.json) تترفع مع بعض على نفس المجلد في أي استضافة، مثلا:
- Firebase Hosting (مجاني ومن نفس المشروع اللي عملتوه بالظبط)
- أو GitHub Pages (مجاني)
- أو أي استضافة عادية عندكم

### 5) قبل ما تستخدموه فعليًا
- غيّروا رقم الواتساب في firebase-config.js (دوروا على WHATSAPP_NUMBER)
- سجّلوا دخول على admin.html بالإيميل والباسورد اللي عملتوهم
- ابدأوا تضيفوا منتجاتكم الحقيقية والأسعار

## طريقة الاستخدام اليومي
- افتحوا admin.html من أي جهاز (موبايل، تابلت، كمبيوتر)، سجّلوا دخول
- أي إضافة أو تعديل أو حذف بيظهر فورًا على index.html في كل الأجهزة التانية من غير أي رفع ملفات
